1Do 是一款自托管 EVM 钱包，主要用于管理经过验证的 EIP-7702 账户 Runtime 及其链上 App 权限。

您可以使用 1Do 创建或导入 EVM 账户、连接支持的硬件钱包、检查并签署交易、管理 Token 和 NFT、连接去中心化应用，以及在支持的网络上激活经过验证的 1Do Runtime。

1Do 会向网站注入标准 EIP-1193 以太坊 Provider，使去中心化应用能够请求账户访问权限和交易。所有敏感请求都会在钱包内展示，并由用户检查和批准。

Runtime 功能仅在已部署并验证 1Do Core 合约的 EVM 网络上可用。

1Do 不使用联属链接或推荐码，也不会从硬件钱包链接中收取佣金。

为了让去中心化应用可以使用钱包 Provider，本扩展程序需要获准在网站上运行。了解更多信息：
https://www.1do.io/
