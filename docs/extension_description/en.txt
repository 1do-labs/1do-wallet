1Do is a self-custody EVM wallet focused on verified EIP-7702 account runtimes and their on-chain app permissions.

Use 1Do to create or import EVM accounts, connect supported hardware wallets, review and sign transactions, manage tokens and NFTs, connect to decentralized applications, and activate a verified 1Do Runtime on supported networks.

1Do injects a standard EIP-1193 Ethereum provider into websites so that decentralized applications can request account access and transactions. Every sensitive request is presented in the wallet for user review and approval.

Runtime features are available only on EVM networks where verified 1Do Core contracts are deployed.

Because the wallet provider must be available to decentralized applications, the extension requests permission to run on websites. Learn more about 1Do at:
https://www.1do.io/
